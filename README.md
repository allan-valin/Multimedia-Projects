# Games
Games developed for university.

## PokeType
(JAR file above)
Small program made to check type weaknesses for Pokemon competitive battling. The difference here is that you can keep add types, without being limited to two of them (it was made like this because some attacks can change a pokemon's type, adding a third one etc.). Because the file is JAR, anti-virus give a false-positive warning.

## IPA Quest
https://dshiryu.itch.io/ipa-quest

A Metroidvania-style game where you collect the symbols that form the International Phonetics Alphabet (IPA).

## NewVRDrums
https://dshiryu.itch.io/newvrdrums

A VR drumming game, inspired by Rock Band and similar titles. There are a few training stages, an air drumming stage and two other that require more precise rhythm. There are over 30 patterns from different music styles to play.

## LAGAGA
https://dshiryu.itch.io/lagaga

A Galaga clone with a roguelike flavor in which the first three levels emulate the original patterns and show all basic mechanics. Starting from the 4th level, the player acquire upgrades for each 10 enemies killed: firerate, multishot, bombs, etc.
