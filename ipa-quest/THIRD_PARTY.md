# IPA Quest: third-party content not in this repo

Unity 2022.3.11f1 (URP, 2D). Packages restore automatically from `Packages/manifest.json`.
Re-import these free Asset Store packs into `Assets/` before opening:

| Folder in `Assets/` | Source |
|---|---|
| `Cainos/` | Pixel Art Top Down / Platformer packs by Cainos (Asset Store, free) |
| `Pixel Adventure 1/` | Pixel Adventure 1 by Pixel Frog (Asset Store, free) |
| `PlatformerSet1/` | free platformer tileset (Asset Store) |
| `TextMesh Pro/` | Window > TextMeshPro > Import TMP Essential Resources |

IPA audio in `Assets/Audio/` comes from the IPA chart audio illustrations (Wikimedia Commons / IPA, CC BY-SA).
Gameplay code in `Assets/Scripts/` follows the Hollow-Knight-style Metroidvania tutorial series
on YouTube; boss/enemy/player scripts adapted from it.
