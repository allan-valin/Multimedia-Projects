# LAGAGA: third-party content not in this repo

Unreal Engine 5 project (Blueprint only). To open it, re-add these packs to `Content/`
via Fab / the Epic launcher, then open `Lagaga.uproject`.

| Folder in `Content/` | Source | Notes |
|---|---|---|
| `StarterContent/` | Epic "Starter Content" (add via Content Browser > Add > Add Feature or Content Pack) | ~600 MB |
| `Characters/` | Epic Third Person template mannequins (create a Third Person template project and copy `Characters/`) | ~400 MB |
| `StarSparrow/` | Star Sparrow Modular Spaceship (Fab, free) | player/enemy ships |
| `StylizedRocksLite_JC/` | Stylized Rocks Lite (Fab, free) | |
| `FreeMaterialPack/` | Free Material Pack (Fab, free) | |
| `LH_95.uasset`, `LH_95_Mat.uasset` | free mesh downloaded online | |
| `TopDown/BGM/`, `TopDown/SFX/` | **licensed audio, bought by the course professor. Not redistributable.** | replace with any 8-bit SFX pack; Blueprint references will need re-linking |

Everything else under `Content/` (Blueprints, Maps, Input, Splash, Cursor, external actors) was made by me.
