# NewVRDrums: third-party content not in this repo

Unreal Engine 5.5 VR project (OpenXR, Blueprint only). To open it, re-add these packs to `Content/`
via Fab, then open `NewVRDrums.uproject`.

| Folder in `Content/` | Source | Notes |
|---|---|---|
| `Maps/Fab/UndergroundSciFi/` | Underground SciFi (Fab, free) | ~2 GB |
| `Maps/Fab/UtopianCity/` | Utopian City (Fab, free) | ~1.6 GB |
| `Maps/Fab/ConferenceRoom/` | Conference Room (Fab, free) | ~500 MB |
| `Maps/Fab/NeonParallax/` | Neon Parallax (Fab, free) | ~240 MB |
| `Maps/Fab/Hollywood_Vol3/` | Hollywood Vol. 3 (Fab, free) | ~110 MB |
| `Characters/MannequinsXR/` | Epic VR template mannequins (create a VR template project and copy) | ~260 MB |
| `DefaultVRFiles/` | Epic VR template + Starter Content | ~680 MB |
| `StarterContent/` | Epic Starter Content | |
| `Drums/3D_Model/` | "Burgundy Drum Kit by Opal" (Sketchfab, free) imported via Blender | ~265 MB |

Paintings used as textures: see `Liscenses.rtf` (Wikimedia Commons, public domain).

Everything else (drum blueprints, hit detection, note/pattern data tables, training/freestyle/airdrum maps,
widgets, splash) was made by me.
